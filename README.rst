This repository is a modified fork of the NIST CDCS `core_main_app <https://github.com/usnistgov/core_main_app>`_
(main functionalities for the curator core project), used by the AsphaltMine (AM) web application.

Modifications
=============

This fork includes modifications for AsphaltMine, in place since 2024-10-31. For the detailed
nature and dates of changes, see this repository's commit history.

Original NIST core_main_app
============================

For the unmodified original, see ``ORIGINAL_README.rst`` and
`https://github.com/usnistgov/core_main_app <https://github.com/usnistgov/core_main_app>`_.
